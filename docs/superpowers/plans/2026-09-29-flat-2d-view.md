# 2D 전투 화면 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 같은 전투를 원근 없는 2D(정사영, XY 평면)로 그리는 `Battle2D` 씬을 3D 씬과 나란히 만든다.

**Architecture:**
- `BoardProjection` 옵션 하나로 보드·유닛·카메라·배경의 기하만 바꾼다.
- 규칙, 재생, 연출, HUD, 레이캐스트 클릭은 3D 와 공유한다.

**Tech Stack:** Unity 6000.3 URP, NUnit(EditMode/PlayMode), Unity MCP, Unity AI(GPT Image 1.5).

**Spec:** `docs/superpowers/specs/2026-09-29-flat-2d-view-design.md`

## Global Constraints

- `BoardProjection` 기본값은 `Perspective3D` 다. 기존 씬·테스트 동작을 바꾸지 않는다.
- `FlatRowScale` = 0.6, `FlatDepthPerUnit` = 0.1, 타일은 칸 중심보다 z +0.02, 발밑 장식은 +0.01, 배경은 z = +5.
- 2D 카메라는 정사영이고, z = -10 에서 +Z 를 본다.
- 검증 절차: Unity MCP 로 Refresh → 콘솔 에러 확인 → `TestBridge.Run` → `Temp/ProjectVoidTestResults.txt`. PlayMode 테스트 뒤에는 Battle 씬을 다시 연다.
- 커밋은 사용자가 요청할 때만 한다.

## Review Focus

1. **2D 에서 유닛 발·그림자와 타일의 앞뒤 순서:** 앞 행 유닛이 뒤 행 유닛·타일을 가려야 하고, 뒤 행 유닛 발이 앞 행 타일에 가리면 안 된다. Task 2·3 은 z 순서를 단언하고, Task 4 는 캡처로 확인한다.
2. **2D 에서 클릭:** 정사영 레이로 칸을 정확히 집는다. Task 2 테스트에서 다룬다.
3. **창 크기 변경:** 정사영 크기를 다시 계산해 보드가 화면 안에 들어와야 한다. `FlatOrthoSize` 테스트와 기존 `Update` 재배치 경로로 다룬다.
4. **배경 그림이 없는 인카운터:** 예외 없이 단색으로 보여야 한다. Task 4 에서 null 경로를 둔다.
5. **3D 씬 회귀:** 기존 테스트 전부 통과로 확인한다.

- [ ] **Step 1: 실패 테스트**

```csharp
[Test]
public void FlatProjectionLiftsFarRowsAndPushesThemBack()
{
    var layout = new BoardLayout(new Vector2Int(3, 3), new Vector2Int(2, 2));
    Vector3 far = layout.WorldCell(Team.Ally, new Vector2Int(0, 0), BoardProjection.Flat2D);
    Vector3 near = layout.WorldCell(Team.Ally, new Vector2Int(0, 2), BoardProjection.Flat2D);
    Assert.AreEqual(layout.CellPosition(Team.Ally, new Vector2Int(0, 0)).x, far.x, 1e-5f, "x unchanged");
    Assert.Greater(far.y, near.y, "far row is higher on screen");
    Assert.Greater(far.z, near.z, "far row is further from the camera");
    Assert.AreEqual(layout.CellPosition(Team.Enemy, new Vector2Int(1, 0)),
        layout.WorldCell(Team.Enemy, new Vector2Int(1, 0), BoardProjection.Perspective3D), "3D unchanged");
}

[Test]
public void FlatOrthoSizeFitsTheBoard()
{
    float size = BoardLayout.FlatOrthoSize(10f, 4f, 16f / 9f, 1.2f);
    Assert.GreaterOrEqual(size * 2f, 4f * 1.2f - 1e-4f, "height fits");
    Assert.GreaterOrEqual(size * 2f * 16f / 9f, 10f * 1.2f - 1e-4f, "width fits");
    Assert.Greater(BoardLayout.FlatOrthoSize(10f, 4f, 4f / 3f, 1.2f), size, "narrow screens need more room");
}
```
